Kubernetes Deployment

  • K3s on Hostinger VPS — namespace devops-lab
  • Manifests: postgres, redis, backend, frontend, services
  • Images pulled from GHCR (commit SHA + latest)
  • Env vars via K8s secrets — no source on VPS
  • Nginx reverse proxy → NodePort frontend & API

Security

  • No hardcoded secrets in source code
  • .env locally · secret.yaml on K8s · GitHub Actions secrets
  • .env.example documents required variables
  • Google credentials & Telegram tokens kept out of git
  • Input validation on API & environment checks at startup

Infrastructure as Code

  • Terraform provisions VPS & cloud resources
  • Declarative config — repeatable, version-controlled infra
  • K8s YAML manifests in k8s/ for workloads
  • GitHub Actions automates apply & deploy steps
  • Same config for dev and production environments

Deployment Strategy

  • Rolling update in K8s deployments (strategy.type)
  • New image tag per git commit SHA on GHCR
  • Readiness probes ensure traffic only to healthy pods
  • Rollback by re-deploying previous image tag
  • Blue-green ready via separate namespaces if needed

Testing

  • 5+ unit tests — frontend Vitest + backend tests
  • API testing — FastAPI /health smoke in CI
  • CI runs pnpm test & alembic upgrade head
  • Docker build validation on every push & PR
  • Tests must pass before CD deploys to VPS
